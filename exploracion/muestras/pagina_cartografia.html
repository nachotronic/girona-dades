    Cartografía digitalizada de secciones censales

    Se facilitan para su descarga los ficheros que contienen la digitalización de los contornos georeferenciados de todas las secciones censales, según coordenadas UTM, huso 30. Los ficheros tienen formato SHAPE.

     

    • Servicios de visualización de datos espaciales WMS

      El Servicio de Mapas Web Web Map Service WMS, es un estándar definido por el OGC (Open Geospatial Consortium – OGC), que permite publicar mapas de datos referenciados espacialmente, de manera dinámica a partir de información geográfica. Este estándar internacional define un mapa como una representación de la información geográfica en forma de un archivo de imagen digital. El WMS también admite la posibilidad de especificar si las imágenes enviadas tienen cierta transparencia permitiendo la sobreposición de capas de diferentes servidores de mapas de otros organismos o capas locales.

    • Servicio de descarga de datos espaciales WFS / API Features

      Este servicio permite acceder a los objetos geográficos proporcionados por los WFS / API Features y se pueden realizar operaciones con diferentes software de ámbito geográfico, tanto de licencia libre (QGIS), como propietaria (ArcGIS).

    Callejero de Censo Electoral

    El callejero contiene toda la información que identifica plenamente las vías y tramos de vía que pertenecen a cada sección censal; como información adicional incluye el distrito postal de cada tramo en cuestión. Se trata de un conjunto de cuatro ficheros (en formato ASCII comprimidos en formato ZIP): fichero de vías, fichero de pseudovías, fichero de tramos de vías y fichero de unidades poblacionales. Los ficheros, que son independientes para cada provincia, son los que el INE utiliza para fines del Censo Electoral.

    Para las publicaciones hasta julio de 2025, el diseño de registro de los ficheros es el que se recoge en el extracto de la Orden de 11 de julio de 1997 sobre comunicaciones electrónicas entre las Administraciones públicas referentes a la información de los Padrones municipales. Para las publicaciones desde julio de 2025 (incluido), el diseño de registro de los ficheros es el acordado por el Consejo de Empadronamiento en su reunión de fecha 11 de noviembre de 2009.

    El fichero con el tipo de vías contiene la denominación de las calles en las diferentes lenguas vernáculas.

    Además, desde 2011 se facilitan las variaciones del callejero entre dos fechas, así como un documento donde se indica el método y las normas para la notificación de variaciones.

    Fichero de variaciones: entre el callejero de enero 2025 y el callejero de julio 2025.

    Se ha producido un cambio en el sistema de gestión del callejero para mejorar la información que se obtiene y, entre otros, se ha incorporado una modificación en el fichero de tramos.

    Hasta la ultima publicación, cuando una vía pertenecía a una sola sección, los tramos que se consideraban eran del 0001 al 9999, para los números impares y del 0002 al 9998, para los pares, independientemente de si se producían saltos en la numeración. Además del 0000S correspondiente a sin numeración.

    Cuando entre en vigor el nuevo sistema de gestión, los tramos de las vías de una sección se obtendrán por agregación de las aproximaciones postales (apps) que pasa a ser el atributo básico que define el territorio y, por tanto, los tramos se formarán con el intervalo de numeración, par, impar o 0000S (sin número) de las apps que figuren en dicha sección. La aproximación postal está definida como la dirección postal hasta portal.

    En la publicación del callejero a 1 de enero de 2021 se ofrecen dos ficheros de tramos obtenidos, uno con la aplicación actual y el otro con la nueva aplicación.

    A partir de la siguiente publicación sólo será posible obtener los tramos con la nueva aplicación.
